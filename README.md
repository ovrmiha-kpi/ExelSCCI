# ExelSCCI

Облік нарядів і робіт за системою рейтингу з автопризначенням. Заміна Excel-таблиці «хто скільки ходив».

Кожен вид наряду дає бали (наприклад, днювальний — 2, ПГД — 1). Застосунок рахує рейтинг кожної
людини, показує, хто відпочивав довше, і сам пропонує, кого ставити в наступний наряд.

Онлайн: https://ovrmiha-kpi.github.io/ExelSCCI/

## Що вміє

- **Динамічна таблиця** — люди × види нарядів. Сортування за будь-якою колонкою, пошук, фільтр за групою
  і статусом, перемикання «кількість / бали», період (весь час, 7/30/90 днів, довільний).
  Підсвічено людей з мінімальним рейтингом — наступні кандидати.
- **Автопризначення** — обираєте дату (або діапазон дат), види нарядів і кількість місць; алгоритм
  обирає тих, у кого менше балів, з урахуванням:
  - статусу (хворіє / відпустка / не призначати — пропускаються),
  - мінімальної перерви між нарядами,
  - хто довше відпочивав, хто рідше ходив саме в цей наряд,
  - «дорогі» наряди роздаються першими, щоб навантаження вирівнювалося.
  План показується до запису — будь-кого можна замінити вручну.
- **Журнал** — усі записи за датами, правка балів і приміток, видалення, експорт в Excel.
- **Люди** — статуси, групи (взводи/відділення), стартові бали для перенесення зі старої таблиці,
  масове вставлення списку з Excel.
- **Види нарядів** — своя назва, вартість у балах, кількість осіб за замовчуванням, колір, архів.
- **Дані** — локально в браузері **або** спільно на сервері (Oracle Cloud) по групі;
  резервна копія в JSON, відновлення, демо-дані.

## Запуск

Лише фронт (дані в IndexedDB браузера):

```bash
npm install
npm run dev
```

Фронт + API (спільні дані по групі, Vite проксує `/api`):

```bash
npm install
npm install --prefix server
# термінал 1
npm run dev:api
# термінал 2
npm run dev
```

Збірка: `npm run build` → папка `dist/`.

Деплой на Oracle Cloud Always Free VM: див. [ORACLE_CLOUD.md](./ORACLE_CLOUD.md)
(Docker Compose: API + статика, volume для даних груп).

## Деплой

При пуші в `main` GitHub Actions збирає проєкт і публікує на GitHub Pages
(у налаштуваннях репозиторію: Settings → Pages → Source: **GitHub Actions**).

Для спільного збереження між пристроями потрібна VM з API (не Pages) — див. ORACLE_CLOUD.md.
