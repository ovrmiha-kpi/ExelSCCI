# DutyRank

Учёт нарядов и работ по системе рейтинга с автоназначением. Замена Excel-таблице «кто сколько ходил».

Каждый вид наряда даёт баллы (например, дневальный — 2, ПГД — 1). Приложение считает рейтинг каждого
человека, показывает, кто отдыхал дольше, и само предлагает, кого ставить в следующий наряд.

## Что умеет

- **Динамическая таблица** — люди × виды нарядов. Сортировка по любой колонке, поиск, фильтр по группе
  и статусу, переключение «количество / баллы», период (всё время, 7/30/90 дней, произвольный).
  Подсвечены люди с минимальным рейтингом — следующие кандидаты.
- **Автоназначение** — выбираете дату (или диапазон дат), виды нарядов и число мест; алгоритм
  выбирает тех, у кого меньше баллов, с учётом:
  - статуса (болеет / отпуск / не назначать — пропускаются),
  - минимального перерыва между нарядами,
  - кто дольше отдыхал, кто реже ходил именно в этот наряд,
  - «дорогие» наряды раздаются первыми, чтобы нагрузка выравнивалась.
  План показывается до записи — любого можно заменить вручную.
- **Журнал** — все записи по датам, правка баллов и заметок, удаление, экспорт в Excel.
- **Люди** — статусы, группы (взводы/отделения), стартовые баллы для переноса из старой таблицы,
  массовая вставка списка из Excel.
- **Виды нарядов** — своё название, стоимость в баллах, число человек по умолчанию, цвет, архив.
- **Данные** — всё хранится локально в браузере; резервная копия в JSON, восстановление, демо-данные.

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build` → папка `dist/` (статический сайт, работает без сервера).

## Деплой

При пуше в `main` GitHub Actions собирает проект и публикует на GitHub Pages
(в настройках репозитория: Settings → Pages → Source: **GitHub Actions**).
